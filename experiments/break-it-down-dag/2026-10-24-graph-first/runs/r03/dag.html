condition — What changes when a percentage is conditional?

Restrict the counted population to cases meeting the condition. Spam among flagged mail uses all flagged mail as its denominator; flagged among spam uses all spam. Reversing those groups changes the question.

prior — What is a base rate or prior?

supported

The spam fraction before considering the current clue. If that fraction is p, the legitimate fraction is 1−p. This population assumption must match the incoming messages for the calculation to apply.

bayes — How does the counting rule become Bayes’ rule?

supported

For a clue E and spam S, spam among clue-bearing messages equals p·P(E|S)/[p·P(E|S)+(1−p)·P(E|legitimate)]. Here P(E|S) means the clue fraction within spam. Multiply to count each contribution, add for all clue cases, then divide for the spam fraction. Denominator must be positive.

vary — How does changing the base rate change this filter’s answer?

supported

Holding 90% detection and 10% false positives fixed: spam among flags = 0.9p/(0.9p+0.1(1−p)). At p=0.001, 0.01, 0.10, 0.50 the answers are approximately 0.8929%, 8.3333%, 50%, 90%. More than half the flagged messages are spam only when p>10%. These comparisons assume the two within-class rates stay fixed.

word — How can a word serve as a clue?

supported

Treat “contains a chosen word” as the clue E in Bayes’ rule, using occurrence rates separately within spam and legitimate mail. For a prior between 0 and 1, a word occurring more frequently within spam raises the spam fraction among messages containing it, but need not make that fraction exceed 50%. Equal nonzero occurrence rates leave the prior unchanged.

joint — What probability is needed for several clues together?

supported

For each class, need the fraction with the full observed pattern together. For two present words A and B, this is the fraction with A in that class multiplied by the fraction with B among that class’s A-containing messages. The second fraction can differ from B’s overall within-class rate. Separate word rates therefore do not determine the joint rate.

independence — What does the naive independence assumption add?

supported

Within each fixed class, assume one feature’s observed value does not change the probabilities of the others. Then estimate the full-pattern likelihood by multiplying the probabilities of all observed feature values, including absent features in a Bernoulli model. This is not a claim that words are independent across all mail.

scores — How do the prior and the observed word pattern form a class score?

supported

For each class, multiply its prior by its estimated full-pattern likelihood. Naive Bayes obtains that likelihood by multiplying the probabilities of all observed feature values within the class. These two scores are unnormalized amounts of model support; each score alone is not the spam fraction among matching messages.

dependence — What goes wrong when two clues repeat the same information?

supported

Constructed counterexample: spam prior 1%; word A occurs in 50% of spam and 10% of legitimate messages; B occurs exactly when A does in each class. For both words present, true joint likelihoods remain 50% and 10%, giving 0.005/(0.005+0.099)=4.8077% spam. Naive multiplication instead uses 25% and 1%, giving 0.0025/(0.0025+0.0099)=20.1613%. Repeated evidence inflated confidence; these are constructed probabilities, not measured spam behavior.

calibration — Does the model’s calculated probability guarantee the true spam fraction?

supported

A normalized model score is conditional on its assumed prior, feature probabilities, and independence. It need not equal the actual spam fraction among comparable messages. Test predictions against relevant labeled mail; useful class decisions alone do not establish trustworthy numerical probabilities.

target — Why is a flag not almost certain spam, how do base rates change the answer, and how do words supply evidence?

supported

Only about 8.33% of flags are spam at the stipulated 1% base rate: false flags from 9,900 legitimate messages outnumber true flags from 100 spam messages. With the same detection and false-positive rates, 10% prevalence yields 50% spam among flags; 50% prevalence yields 90%. A word’s occurrence is another clue in the same update rule. Labeled messages can supply class and word rates; naive Bayes combines observed word values under independence within each class and normalizes prior-weighted likelihoods. Dependent words can make that model probability unreliable.

multiply — How do within-group rates become fractions of all mail?

supported

If p of all messages are in a group, and fraction q of that group has a clue, fraction p×q of all messages has both properties. In a population of N messages the expected count is N×p×q.

partition — How do contributions from different classes form the clue total?

supported

Spam and legitimate mail do not overlap and together cover all mail. All messages with a clue therefore equal clue-bearing spam plus clue-bearing legitimate messages. Add these class contributions; do not average their within-class percentages without weighting by class size.

feature_value — What probability should an absent word contribute?

supported

For a binary word with occurrence rate q within a class, use q if present and 1−q if absent. For example, a word present in 75% of spam is absent in 25% of spam. Do this separately for each class.

normalize — How do the two class scores become a model probability?

supported

Divide the spam score by the sum of spam and legitimate scores. Both scores together account for all classes for the observed pattern under the model. A shared denominator can be omitted when only choosing the larger class score, but it is required for the probability. If both scores are zero, normalization is undefined; an unseen training pattern is not evidence of impossibility.
