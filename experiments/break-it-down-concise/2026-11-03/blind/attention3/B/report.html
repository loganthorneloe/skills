The short answer

Attention lets every token in a text pull in information from every other token in one step. For each position it scores every other position with a dot product of learned vectors, turns the scores into weights that sum to one, and takes the weighted average of what those positions offer. It is matrix multiplications plus one softmax.

It made ChatGPT possible by being trainable at scale. Earlier models read one token at a time; attention processes the whole sequence at once and links any two tokens directly. That let researchers train far larger models on far more text, which kept improving as they grew. ChatGPT is one of them, further trained on human feedback.

What attention computes

A language model predicts the next token, a word or word fragment. Each token starts as an embedding, a learned vector (512 numbers in the original Transformer, 12,288 in GPT-3). Training nudges every number in the model to raise the probability of the token that actually came next, using each number's gradient, the derivative of the error with respect to it. The hard part is context: "bank" should mean different things in "river bank" and "bank loan", so each token's vector needs a way to absorb information from the others.

Stack the embeddings as rows of a matrix X. Attention multiplies X by three learned matrices to give each token a query (what it is looking for), a key (what it can be matched on), and a value (what it hands over). Token j's relevance to token i is i's query dotted with j's key. A softmax exponentiates each row of scores and divides by the row's total, giving weights that sum to one, and token i's output is the weighted sum of the values. For the whole sequence:

Attention(Q, K, V) = softmax( Q·Kᵀ / √dk ) · V

Here dk is the length of each query and key. The paper's diagram draws the same equation as a pipeline, read from the bottom:

A worked example with three tokens

Suppose the text is "the dog barked" with two-number embeddings the = [1, 0], dog = [0, 1], barked = [1, 1], and these weight matrices:

WQ = [[1, 0], [1, 2]]

X·WQ gives queries the [1, 0], dog [1, 2], barked [2, 2].

WK = [[2, 0], [0, 1]]

X·WK gives keys the [2, 0], dog [0, 1], barked [2, 1].

WV = [[1, 0], [0, 3]]

X·WV gives values the [1, 0], dog [0, 3], barked [1, 3].

The query of "barked", [2, 2], dotted with the three keys gives 4, 2, and 6; divided by √2 that is 2.83, 1.41, and 4.24. A language model may not look ahead, so each earlier token's scores against later tokens are set to minus infinity, which softmax turns into exactly zero.

Why the scores are divided by √dk

If one score is much larger than the rest, softmax gives it nearly all the weight and the weights barely respond when scores change, so gradients become tiny. Dot products grow with length: if the components of q and k are random with mean 0 and variance 1, their dot product "has mean 0 and variance dk". Dividing by √dk restores variance 1. The authors present this as a suspicion, not a proof.

Components are drawn from a standard normal, as in the paper's footnote; trained vectors are not random, so this isolates the effect of length. The original Transformer used dk = 64.

The mask, the heads, and the rest of the layer

The minus-infinity mask is what makes this a next-token predictor. Each position attends only to itself and earlier ones, implemented "by masking out (setting to −∞) all values in the input of the softmax which correspond to illegal connections." Because no position sees its future, one pass over a 2,048-token passage trains 2,048 next-token predictions at once.

Multi-head attention runs several smaller attention functions in parallel, each with its own projections, so different heads can follow different relationships; the outputs are joined and projected once more. The original used 8 heads of size 64, GPT-3 96 of size 128. Attention by itself ignores order, so a positional encoding vector is added to each embedding. Each layer then passes every token separately through a small feed-forward network, and models stack many layers: 6 in the original, 12 in the first GPT, 96 in GPT-3. Attention is the only place tokens exchange information.

Why it made models like ChatGPT possible

Before 2017, the standard language models were recurrent neural networks such as LSTMs, which read one token at a time and compute each new state from the previous one. But a next-token predictor is not yet an assistant. OpenAI says "ChatGPT is fine-tuned from a model in the GPT-3.5 series" and trained "using Reinforcement Learning from Human Feedback (RLHF), using the same methods as InstructGPT": people write and rank answers, a second model learns the rankings, and the language model is trained to score well on them.

Limits

Attention compares every token with every other, so doubling the context quadruples that work. GPT-3, for example, fixed its context at 2,048 tokens and restricted some layers to nearby tokens, a shortcut the original paper proposed for long sequences.

The sources show attention was the architecture used and why it trained and scaled well; none tests whether another architecture could have produced ChatGPT. "Made it possible" means the practical route taken, not the only conceivable one. ChatGPT's own architecture is unpublished, so its details are inferred from GPT-3 and InstructGPT.
