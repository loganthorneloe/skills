# Break It Down concision study

Ablation and prompt experiments that cut Break It Down reports to about half their length while keeping research quality, visuals, and coverage. The findings led to the version 3 distill step and the reuse-rights rule now in `skills/rtg/research/break-it-down/`.

- [Report](2026-11-03/report/index.html)
- [Protocol](2026-11-03/protocol.md)

Agent working files, screenshots, the private brand kit copy, and captured source figures are kept local and not committed, so run reports show missing images and the report renders unstyled until the kit is reinstalled with `logan-style/scripts/install_web.py`.
