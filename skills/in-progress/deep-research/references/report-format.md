# Deep-research report format

Read completely immediately before drafting or revising the report.

## Writing

- Lead with the answer; omit throat-clearing and generic background.
- Prefer compact bullets, tables, and short sections over prose walls.
- Include dates, quantities, scope, and caveats needed for precision.
- Distinguish verified fact, inference, disputed claim, unknown, and recommendation.
- Keep one material claim per bullet when practical.
- Place a descriptive Markdown citation directly after the supported wording.
- For pivotal claims, include the exact datum and a page/table/section locator or short quotation when useful.
- Remove repetition and process narration without deleting material evidence or uncertainty.

## Sections

Use only needed sections, in this order:

1. `# <Report title>`
2. `## Answer` — direct synthesis
3. `## Key findings` — evidence-dense bullets/tables
4. `## Contradictions, limitations, and unknowns`
5. `## Implications` or `## Recommendation` — only when useful/requested
6. `## Method` — compact scope, search date, restrictions, and major exclusions
7. material unanswered questions, when any
8. `## Sources` — always final

Never add sections merely to make the report appear comprehensive.

## Bibliography

`## Sources` must:

- include every source cited or materially relied upon;
- exclude discarded candidates and search snippets;
- deduplicate shared evidence chains;
- identify author/organization, title, publisher/site, publication date when available, and direct URL;
- mark partially reviewed or inaccessible sources;
- use retrieval date when publication date is unavailable;
- sort alphabetically unless numbered citation order is materially clearer.

Every inline source must appear in the bibliography; every bibliography item must have informed the report.
